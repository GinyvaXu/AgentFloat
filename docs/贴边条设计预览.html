贴边条 · 具体设计预览

四种灰色竖条，贴在浮球右侧；鼠标悬停变宽。看体积、对比度、信息量哪个合适。
A · 极简三点条
14×40，纯灰，三颗点；最轻，但任务数不可见
hover 20px
适合：只想提示“有任务”，不想抢注意力
B · 三点 + 任务数
14×40，顶部蓝点 + 底部任务数；信息量刚好
3
hover 20px
推荐：一眼知道有 3 个后台任务
C · 弧形光条
10×56，渐变 + 顶部高光；更像“环境的一部分”
hover 16px
适合：完全不打扰，但可发现性弱
D · 数字胶囊
20×64，直接显示任务数；最显眼
3
hover 26px
适合：任务少、希望一眼看到数量
