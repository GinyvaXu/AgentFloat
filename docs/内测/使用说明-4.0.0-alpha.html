AgentFloat 使用说明4.0.0-alpha 内测

一个桌面浮球，用来快速启动 AI Agent、看后台任务进度、管 Skills、盯 API 余额。

1. 安装

  • 双击 AgentFloat-Setup-4.0.0.exe，一路下一步（无需管理员权限）。
  • 安装完自动启动，屏幕右下角出现一个浮球。
  • 内测版每次启动都会播一遍新手引导，这是故意的；按 Esc 或点「跳过」立刻结束。
  • 数据目录（卸载不会自动删）：
    %APPDATA%\AgentFloat（配置/日志）
    %LOCALAPPDATA%\Programs\AgentFloat（程序）

2. 浮球的三种操作

操作发生什么
单击默认弹一句语录；可在设置里改成「启动主 Agent」
长按 0.6 秒启动当前主 Agent（默认 OpenCode Desktop，可在「设置 → Agent 管理」换）
右键环形菜单：Agent 列表、Skills、进度驾驶舱、设置、退出
长按提示「命令路径不存在」：去「设置 → Agent 管理」把路径改成真实 exe；4.0 起也会自动在 Programs 目录兜底查找。

3. 环形菜单

  • 右键浮球 → 一圈图标，点哪个启动哪个。
  • 「设置 → 环绕菜单」可增删、改顺序、换颜色和图标字符。
  • 菜单项可以是终端 CLI（Claude Code / Codex / OpenCode CLI）、桌面应用、或网页模式。

4. 后台任务进度（D 线）

贴边条：浮球旁一条竖条，显示 ••• 和任务数。点一下展开面板。
琥珀色 = 需要你确认（同时弹系统通知）；红色 = 失败。
展开面板：点任务行看步骤明细，底部「打开驾驶舱」看全部历史和回放。
  • 运行中的任务默认持续 2 分钟才出现，避免一闪而过；需要确认/失败立刻出现。
  • 面板 10 秒无操作自动收起；Esc 关闭，— 收回成贴边条。
  • 不想看：设置 → 通用 → 关闭「进度贴边条」。
  • 想让自己写的 Agent 也汇报进度：设置 → Skills → 「自动接入 MCP」，会往 OpenCode / Claude / Cursor 配置写入 af-mcp（先备份原文件）。

5. AI 接入（供应商 / 余额 / Token）

  • 「AI 接入」页 → 「+ 添加供应商」→ 选预设（DeepSeek / OpenRouter / OpenCode Go…）或自定义。
  • 填 Base URL、模型、API Key；Key 只存本地 config.json，页面不回显、不写日志。
  • 金额型（DeepSeek、OpenRouter）显示余额；订阅型（OpenCode Go）只显示已用百分比，不计入总余额。
  • 顶部是总余额 / 今日 Token / 本月 Token；下方是今日、本月、分用途统计。
  • 「切换」只影响 AI 快报和 Skills 翻译，不改你的 Claude / Codex 配置。
余额显示「HTTP 401」= Key 无效或过期；「字段缺失」= 余额接口结构变了，改「余额字段」即可。

6. Skills 车间

  • 浏览 skills.sh 榜单，点进去看 SKILL.md 摘要。
  • 安装前检查依赖、冲突和覆盖；支持一次装到多个 Agent（矩阵/作用域）。
  • 安装前自动备份，出问题可在「备份与恢复」回滚。

7. 其他

AI 快报

定时抓取资讯并生成摘要，可导出。用哪个模型由「AI 接入」的当前供应商决定。

喝水助手

定时提醒，可设全屏遮罩 / 居中弹窗 / 仅托盘气泡。

主题与启动动画

设置 → 通用：深色/浅色、启动动画、浮球大小与贴边行为。

退出

右键浮球 → 退出；托盘图标右键也有退出。关窗口不等于退出。

8. 常见问题

Q：长按没反应 / 提示路径不存在？
设置 → Agent 管理，确认「OpenCode Desktop」指向 …\Programs\ai.opencode.desktop\OpenCode.exe。

Q：贴边条一直不出现？
① 任务运行不足 2 分钟；② 设置里关掉了进度贴边条；③ 之前按过 Esc 关闭，需要等任务内容变化或去设置重新打开。

Q：新手引导每次都弹，烦？
内测版行为，正式版只播一次。现在按 Esc 即可跳过。

Q：Key 会被上传吗？
不会。Key 只写本地 %APPDATA%\AgentFloat\config.json，请求直连你填的端点。

Q：怎么彻底卸载？
设置 → 应用 → AgentFloat 卸载；再手动删 %APPDATA%\AgentFloat 可清配置。
