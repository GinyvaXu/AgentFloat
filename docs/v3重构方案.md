## 三、目标架构

### 3.1 目录结构（src 包化）

```
agent_float.py              # 保留瘦入口（兼容 python agent_float.py 与现有构建习惯）
pyproject.toml              # 包定义 + pytest 配置（src layout）
requirements.txt / requirements-dev.txt
src/agentfloat/
  app.py                    # 应用引导（QApplication / 托盘 / 生命周期 / 热键）
  core/                     # paths / config(含迁移) / logging / theme tokens(唯一来源) / launcher
  ui/
    floatball/              # 浮球：widget(渲染) + interaction(状态机，纯逻辑可单测) + edge(贴边)
    radial/                 # 环菜单：layout(几何/命中，纯逻辑) + menu(渲染)
    motion.py               # Qt 弹簧动画引擎（果冻曲线 + 物理弹簧）
    panels/                 # skills / clipboard / command / water（Qt 轻面板）
    splash.py / loading.py  # 启动动画 / 加载指示器
  services/                 # api_monitor / news / skills / water / update / dsh / local_ai
  webshell/                 # FastAPI 服务 + bridge + pywebview 窗口 + WebAppHandlers
web/                        # 前端静态资源（保持根级，PyInstaller 链路不变）
tests/                      # pytest（纯逻辑优先）
versions/                   # 本地归档（不上传）
```

### 3.2 设计系统（唯一来源，照搬 ProjectDock）

- **色板**：亮 `#f2f2f7 / #1d1d1f / #6e6e73 / #0a84ff`；暗 `#000 / #1c1c1e / #f5f5f7 / #0a84ff`；语义色 `#ff3b30 / #34c759 / #ff9500`
- **材质**：玻璃 `blur(24px) saturate(180%)`；卡片 `rgba(255,255,255,.72)` / `rgba(44,44,46,.6)`
- **圆角**：主 12px / 小 9-10px / Logo 13-14px；字体 SF Pro Text → PingFang SC → 微软雅黑
- **动效**：按压缩放 `scale(.96)` + 果冻曲线 `cubic-bezier(.34,1.56,.64,1)`；弹簧（stiffness 220 / damping 26）；reduced-motion 降级
- **浮球**：圆角方块 + AgentFloat 渐变标识（P2 出 2-3 个静态预览图，选定后实现）

### 3.3 交互模型（浮球状态机规则草案）

```
press ──(移动 >4px)──────────→ drag（取消全部定时器）
  │
  ├──(按住 ≥500ms)──────────→ radial 菜单
  └──(提前 release)─────────→ click 启动主 Agent（mousedown 即给缩放反馈）

hover 400ms → 唤出菜单，但四类抑制：
  ① 贴边唤出后 600ms 内   ② 拖拽结束后 400ms 内
  ③ 菜单关闭后 500ms 内   ④ 按压期间
```
