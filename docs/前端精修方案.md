# AgentFloat 前端精修方案（v3.14）

> 依据：`impeccable`（**Operate / Read** 模式）+ 全量前端审计（Qt 层 `src/agentfloat/ui/**` 与 Web 层 `web/**`）
> 定位：**保形精修（Refinement）**——保留毛玻璃、品牌渐变、Apple 风与现有信息架构，不换视觉世界。
> 三条主线：①**单一来源**（令牌/组件收敛）②**层级与可读性**（字号/对比度/间距刻度）③**可信度**（危险操作、状态完整性、反馈统一）

---

## 0. 已核实的问题（先修）

| 编号 | 问题 | 证据 | 影响 |
|---|---|---|---|
| P1 | Qt 字号层级被全局 QSS 压平 | `panel_style.py:49` 有 `QLabel { font-size: 12px }`，而 `water.py` 给大数字设了 `QFont(..., 30, Bold)`——Qt 中**样式表优先级高于 setFont**，30pt 被压成 12px | 喝水面板的杯数（视觉焦点）、Skills 中文详情 14px、process_panel 13px 全部失真 |
| P2 | Web 浅色灰阶不达 AA | `--hint #98989D` ≈ **2.9:1**（暗色 4.8:1 合格），却用于 11–12px 次要文案，连「有未保存的修改」都用它 | 浅色主题下几乎读不清 |
| P3 | 语义标签文字色不达 AA | `style.css:220-224` 直接拿 OK/WARN/ACCENT 本色做 11px 文字：绿 ≈2.2:1、红 ≈3.6:1、蓝 ≈3.7:1 | 状态徽章看不清 |
| P4 | 危险操作确认不统一 | API 页一半用原生 `confirm()`、一半自绘 modal；剪贴板「清空全部」「删除此条」、登出、清空显示行、删字段**完全无确认** | 误触即丢数据 |
| P5 | 禁用态缺失 | `#pkGhost/#pkPrimary` 无 `:disabled` 样式（Skills「复制」禁用后仍是强调色）；Web 两套（0.35 / 0.4 + cursor 不一） | 看起来能点却点不动 |
| P6 | 主导航键盘不可达 | `web/index.html:22-26` 的 `<a data-page>` 无 href/tabindex/role，激活态只有颜色+加粗 | 键盘用户无法切页 |

## 1. Qt 层改造清单

**1.1 字号单一来源（P1）**
- 把各面板 `setFont/setPixelSize` 的字号全部收进 QSS（用 `FONT` 令牌），或给这些标签加 objectName 并在 QSS 中显式声明字号
- 涉及：`water.py`（杯数 30 / 标题 11 / 状态 10）、`skills.py`（详情 14 / 列表 12/11）、`news_window.py`、`process_panel.py`、`quote_window.py`
- 顺带清理：`quote_window.py` 15px 与 `pt` 混用、`process_panel.py` 13px（不在字号档）、`radial_menu.py` 7pt/8pt（≈9/11px，低于最小档）

**1.2 卡片底色收敛（CARD 令牌）**
- 现在暗色卡片三种：#333336 / #2C2C31 / #2c2c31；Web `--surface2` 又是 #333336
- `core/theme.py` 增 `CARD`，Qt/Web 同源

**1.3 菜单样式单源**
- `floatball.py:2349-2358` 与 `app.py:609-624` 是同一份 QMenu 样式复制两份（已开始漂移）
- 抽 `ui/menu_style.py`，用 `RADIUS/SPACE` 生成；顺手删 `floatball.py:2359-2363` 里重复 `QMenu(self)`（当前泄漏一个）

**1.4 flash / 空态统一**
- flash 现有 4 套实现 → 全部走 `kit.PanelShell.flash`（`news_window._flash` 目前只 setText 从不清除，会永久占住 footer）
- 空态 4 种用法 → 列表内插 `kit.empty_state` 行（Skills 左列 0 条时是纯白空列表）

**1.5 间距刻度落地**
- 现在 `SPACE.xs+2`(=6)、`SPACE.sm+2`(=10) 这类表达式产生 6/8/10/12 四个值，刻度形同虚设
- 令牌里显式补档（6/10），禁止 `+2` 表达式

## 2. Web 层改造清单

**2.1 对比度（P2/P3）**
- 浅色 `--hint` → `#6E6E73`；「未保存修改」改 `--text2`
- 语义标签文字用深一档色板（绿 #1B8A3C / 红 #D70015 / 蓝 #0066CC），底色不变

**2.2 键盘与语义（P6）**
- 主导航改 `<button>` + `aria-current="page"` + `:focus-visible` 焦点环
- Toast 加 `role="status" aria-live="polite"`；modal 加 `role="dialog"` + 聚焦首输入 + 简易 focus trap

**2.3 组件收敛（消除重复定义）**
- 6 套胶囊标签 → `.chip` + 修饰类；5 套按钮 → `.btn`(.sm/.primary/.danger)；5 套卡片 → `.card`(.tight/.flat)
- 删重复：`code` 定义两次、`.news-item` 两次、`--radius`/`--card-radius` 收敛到 `--r-md`/`--r-lg`
- 动效时长全部走 `--dur-*`（现仍有 `.15s`/`0.25s`/`0.3s` 自写）

**2.4 状态补齐**
- 加载：三处「加载中…」纯文字 → 骨架屏 + 超时提示
- 错误：API 页错误卡片 + 「重试」+ 可折叠原始错误
- 危险操作：确认组件（普通 / 危险 / 需输入校验），替换原生 `confirm()`

**2.5 细节**
- 输入宽度刻度（现 170/200/220/240/260 混用）；卡片内距统一 16/20、外距 12；禁用态统一 0.4 + 同 cursor；省略号统一 U+2026

## 3. 跨端统一

- 图标语言：Web 用 emoji（🧭⚙⬇¥N）、Qt 用字母符号（S/¥/⌘/水/移）→ 定义一套共享映射
- 自动关闭默认值：Qt 12s / Web 表单 8s / 卡片兜底 8s → 收敛到 config 默认表一处
- 快报字号：Web 有「字号/密度」设置，Qt 固定 12px → Qt 读同一配置
- 「设置...」三点 vs 「设置…」→ 统一 U+2026

---

## 4. 改动不碰什么（保形边界）

- 毛玻璃外壳、品牌渐变（#0A84FF → #AF52DE）、圆角体系（4/8/10/14/16/999）、Apple 风排版基调
- 信息架构与文案事实（除 UX 文案打磨外不改其含义）
- 已有动效手感（本次只统一时长/曲线令牌，不调弹簧参数）
- 用户数据、配置键名、外部接口

---

## 5. 验收清单（12 条，可逐项检查）

1. 全项目 `setFont/setPixelSize` 不再出现字号（`rg "setPixelSize|QFont\(.*,\s*\d+"` 归零）
2. 硬编码 hex 从当前 ~140 处降到 ≤30 处（且集中在色板定义文件）
3. 浅色/暗色两套主题下：正文 ≥4.5:1、次要文案 ≥3.5:1、标签文字 ≥4.5:1
4. 危险操作 100% 有确认或撤销（剪贴板清空、删除条目、登出、清空字段）
5. 所有按钮/输入框有禁用态样式，且禁用态与可点态可区分
6. Tab 键可走完 Web 主导航 → 页面内容 → 顶栏操作，焦点始终可见
7. 空列表不再是纯白/空白，都有空态行
8. 加载状态不再是单行文字（骨架或带耗时/超时）
9. 错误状态都有「重试」入口
10. Web/CSS 中同类组件只剩一套基础类 + 修饰类（按钮/胶囊/卡片）
11. Qt 三个面板字号层级恢复正常（喝水杯数 30px、Skills 详情 14px、报头 12px）
12. 深浅主题切换后无残留硬编码色错配（重点：process_panel/water/loading_indicator）

## 7. 风险与回退

| 风险 | 应对 |
|---|---|
| Qt 样式表改动波及已适配的深浅主题 | 每批只动一层；改动后抓图对照（沿用 `grab()` 预览法） |

| 回归 | 每批独立提交；`git tag pre-polish`；二进制回退 `versions/v3.13.2/dist` |
