## 二、施工项

### 1. 应用图标（exe / 任务栏 / 托盘 / 窗口 / README）
- 用 `agent-float.ico` 覆盖 `assets/agent_float_icon.ico`；用 `agent-float-icon-1024.png` 覆盖 `assets/agent_float_icon.png`。
- 检查并同步引用点：`AgentFloat.spec`（PyInstaller `icon=`）、`setup.iss`（Inno Setup）、托盘与窗口 `setWindowIcon`、README 头部 `<img src="assets/agent_float_icon.png">`、启动动画资源（若引用了图标位图）。
- 替换后构建调试版，逐一验证：资源管理器 / 任务栏 / 托盘 / 窗口标题栏 / Alt-Tab，并检查 100% 与 150% DPI 下的 16–256px 表现。

### 2. 浮窗图像（`src/agentfloat/ui/floatball.py`）
当前方案 C = 深色玻璃球 + 品牌渐变描边（`#0a84ff→#af52de`）+ 白色旋涡（代码绘制）。两种做法二选一：

- **方案 A（推荐，改动最小、保留玻璃质感）**：玻璃球与渐变描边不动，只把**旋涡**的绘制换成新旋涡 —— 用 `agent-float-swirl-512.png`（或 `-128.png`）作为纹理绘制，或按新旋涡形状重绘路径。要求：52px 下清晰、居中、hover/按压缩放不变形。
- **方案 B（改动较大、与图标 1:1）**：直接用 `agent-float-icon-rounded-512.png` 作为浮窗位图。需保留：贴边吸附、拖拽、轮盘唤出/收合、启动动画；并确认 52px 下的清晰度与投影效果。

验收：浅色 / 深色壁纸下都清晰；16 / 32 / 52px 三档可辨；轮盘与吸附交互、启动动画无回归；重绘性能无明显下降。
