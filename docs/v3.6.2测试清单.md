# AgentFloat v3.6.2 安装测试清单

> 安装位置：`%LOCALAPPDATA%\Programs\AgentFloat`（开始菜单 + 桌面快捷方式，可在「设置 → 应用」卸载）
> 配置目录：`%APPDATA%\AgentFloat`（与便携版共用，旧设置会保留）
> 反馈方式：把勾不上的条目标出来 + 描述现象（可附 `%APPDATA%\AgentFloat\logs\AgentFloat.log` 末尾）

## 0. 启动动画（v3.6.2 新增）
- [ ] 启动时**屏幕中心**出现光晕 + 扩散圆环 + **旋转弧环** + 星点 + 放大回弹的浮球
- [ ] 浮球比首版**更小巧**，带轻微上下浮动与摇摆（更有动感）
- [ ] 中心出现一行字：**版本号 + 问候语**（如 `v3.6.2 · 欢迎回来`），**带半透明胶囊底**，深浅壁纸都清晰
- [ ] 听到「叮—咚」提示音（音量可在 设置 → 通用 → 启动动画 里调；可关闭音效）
- [ ] 动画后半段浮球**缩小并飞向落点**，落位瞬间有**闪光 + 三圈涟漪**从落点扩散
- [ ] 涟漪期间浮球即可交互（无跳变/闪烁/重影）
- [ ] 动画期间点击屏幕/按 Esc **不会跳过**（按设计：不可跳过）
- [ ] 多屏：动画出现在**浮球所在那块屏幕**的中心（副屏也居中）
- [ ] 设置 → 通用 → 启动动画：关闭「播放启动动画」后，下次启动直接出现浮球（无动画无声音）
- [ ] 问候语自定义生效（留空则每次随机一句）

## 1. 安装与启动
- [ ] 双击 `AgentFloat-Setup-3.6.2.exe` 完成安装（无管理员弹窗）
- [ ] 开始菜单出现「AgentFloat」，桌面有快捷方式（如勾选）
- [ ] 首次启动出现启动动画，浮球出现在屏幕上（副屏也能正常显示）
- [ ] 设置 → 关于：版本显示 **v3.6.2**
- [ ] 卸载入口可用（设置 → 应用 → AgentFloat，或开始菜单「卸载 AgentFloat」）

## 2. 浮球基本交互
- [ ] 单击浮球 = 启动主 Agent（默认 Claude Code / 你设置的主 Agent）
- [ ] 按住不动约 2 秒 = 环形进度条走满后启动
- [ ] 按住并立即向外滑 = 环形菜单展开；松手执行选中项（动画播完才执行）
- [ ] 从环形菜单进入「移动」后，可拖动浮球，左键放置 / 右键或 Esc 取消
- [ ] 悬停仅有放大反馈，**不会**自动弹菜单
- [ ] 贴边吸附/隐藏：鼠标靠近从边缘弹回；隐藏延迟正常
- [ ] 右键菜单 / 托盘菜单可用；主题切换正常（设置 → 通用 → 主题）

## 3. Agent 进程面板（悬停浮球 ~0.25 秒）
- [ ] 悬停浮球弹出面板；鼠标移到面板上不会立刻消失；离开约 0.4 秒收起
- [ ] 面板**滚轮**可缩放（0.8×–1.8×）、**Ctrl+滚轮**调不透明度，松手自动保存
- [ ] 设置 → 通用 → 行为：面板大小 / 面板不透明度滑杆生效
- [ ] 启动一个 Agent 后面板显示：状态点、PID、运行时长、最近活动
- [ ] 点「中断」下拉**停留**可选项（不再自动消失）→「软中断」发出 Esc
- [ ] 「结束进程…」有确认框；结束后该 Agent 显示「已中断」+「继续任务」
- [ ] 点「继续任务」：进程仍在时注入 continue；进程已结束时按 resume_args 重启续接
- [ ] 没有运行中的 Agent 时显示「没有正在进行的 Agent 进程」

## 4. 余额显示框
- [ ] 显示框内容与设置页「实时预览」一致
- [ ] 拖动框体移动位置；拖**右下角**缩放；**滚轮**调大小；**Ctrl+滚轮**调不透明度（自动保存）
- [ ] 设置 → API 用量 → 余额显示框：大小 / 不透明度滑杆、上/下位置、行预设、显示行编辑
- [ ] 点「行预设 ＋ OpenCode Go」→ 保存 → 立即拉取：显示 `5h xx% / 周 xx% / 月 xx%`
- [ ] 低余额（剩余 <20%）时显示框变红

## 5. API 用量页
- [ ] 端点卡片：正常/异常/等待状态、字段值、错误原因与排查建议
- [ ] 「测试」按钮即时验证且结果回显到卡片
- [ ] 「立即拉取」不等轮询即可刷新（卡片与显示框同步更新）
- [ ] 「＋ 预设」按钮：OpenCode Go / DeepSeek / Kimi / SiliconFlow / OpenRouter
- [ ] 重复添加同一预设**不会**产生重复卡片（提示「已用预设更新」）
- [ ] 若存在占位/重复端点，顶部出现提示条与「一键整理」
- [ ] 「＋ 自定义端点」可增删改；「复制」按钮生成副本

## 6. 账户与密钥（设置 → 账户与密钥）
- [ ] 输入账户名与口令后**按回车**可直接提交（也可点按钮）
- [ ] 新建账户成功 → 页面切到「已解锁」，显示当前账户
- [ ] 勾选「在此设备记住」后，重启应用自动快速登录（日志含「快速登录成功」）
- [ ] 「登出」后密钥需重新登录才能查看
- [ ] 添加密钥（如 `OPENCODE_GO_API_KEY`），列表显示掩码
- [ ] 「复制」可复制完整值（剪贴板不可用时退回「显示」弹窗）
- [ ] 「编辑」改名/改值/备注；「删除」有二次确认
- [ ] 多账户：新建第二个账户 → 切换 → 各账户密钥互不可见
- [ ] 「修改口令」后旧口令登录失败、新口令成功，且原密钥仍在

## 7. 配置导出 / 导入
- [ ] 输入两次相同的导出密码 → 「导出 .afpack」→ 提示保存路径（默认桌面）
- [ ] 用记事本打开导出文件：**看不到**明文密钥/密码
- [ ] 选择该文件 + 密码 → 「预览」显示账户/版本/Agent 数/端点数/密钥名
- [ ] 密码输错 → 明确报「口令错误或数据已损坏」
- [ ] 「确认导入」后配置生效（主题/Agent/端点一致），密钥合并（同名覆盖）
- [ ] 导入后窗口位置未被文件覆盖（仍在你当前放置的位置）

## 8. 启动注入与退出行为
- [ ] 登录保险箱后启动 Agent，Agent 环境里能看到保险箱密钥
      （可在 Agent 里执行：`echo %OPENCODE_GO_API_KEY%`）
- [ ] 关闭 AgentFloat **不会**结束正在运行的 Agent 进程
- [ ] 重新打开 AgentFloat，浮球回到上次位置；设置项保留

## 9. 稳定性与日志
- [ ] 连续使用 10 分钟无崩溃、无卡死（浮球可拖动、菜单可开）
- [ ] 日志（`%APPDATA%\AgentFloat\logs\AgentFloat.log`）末尾无 `[ERROR]` / `Traceback`
- [ ] 退出应用后任务管理器无残留 AgentFloat 进程
