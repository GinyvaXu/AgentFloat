# AgentFloat UI 适配全量审计

> 日期：2026-10-28 ｜ 状态：审计完成，未改代码 ｜ 范围：贴边吸附、自动弹出、教程面板、所有弹出面与 Web 指南
> 方法：3 组只读代码审计 + 本机 Qt 屏幕探测 + 关键几何复现
> 现场：单屏 2560×1600 物理，Windows 缩放 200%，Qt 逻辑屏 **1280×800**，DPR **2.0**

> **已确认口径（2026-10-28）**
> - 本轮**只出报告，不改代码**；修复排期另定。
> - 贴边隐藏的可见把手改为 **10–12px 可点击把手**（不再保留 6px）。
> - AI 日报**保留自动弹出，但不抢焦点**（`WA_ShowWithoutActivating`，并限制尺寸）。
> - 修复方案仍建议走「统一适配层」，不建议逐点打补丁。

## 0. 结论先行

这不是一个坐标 bug，而是 **5 个系统性缺口**：

1. **屏幕上下文不稳定**：贴边隐藏后用「屏幕外的窗口中心」反推屏幕；切屏、唤出、轮盘、检测器各算一套。
2. **弹出面没有统一锚点定位**：Skills / 剪贴板 / 命令 / 喝水四个面板直接 `show()`，由 Qt 居中到浮球，尺寸又固定。
3. **贴边状态机 + 动画/定时器有竞态**：`_reveal_now` 会停掉自己刚启动的动画；关闭吸附不先弹出；悬停计时器不复查。
4. **教程覆盖层没有跟随真实浮球**：首启时浮球默认贴边隐藏，教程却从隐藏位起播；演示又会移动浮球，覆盖层仍用旧位置。
5. **适配基准过期**：测试仍按 1707×1067（150%）写，当前是 1280×800（200%）；多屏、负坐标、任务栏、混合 DPI 缺测试。

**建议不要逐点打补丁，先做一层统一适配层。** 否则每修一个面板，另一个面板还会复现同类问题。

## 2. 现场与基线

本机 Qt 实测（开启 HighDPI 后）：

```text
screens: 1
geometry:        (0, 0, 1280, 800)
availableGeometry:(0, 0, 1280, 800)
devicePixelRatio: 2.0
```

这意味着：

- 所有 Qt 尺寸都是**逻辑像素**，物理像素 ×2。
- 660×520 的 Skills 面板在屏幕上占 **52%×65%**。
- 1000×640 的 AI 日报窗占 **78%×80%**。
- 测试里的 1707×1067 是 2560×1600 @150% 的旧逻辑尺寸，已经不代表当前现场。

## 3. P0：会直接造成「贴边回不来 / 教程跑偏 / 面板盖住浮球」

### P0-1 贴边隐藏后，按屏幕外的中心选屏

**代码**：`floatball.py::_screen_geometry()` 使用 `self.geometry().center()` 调 `QApplication.screenAt()`。

右贴边隐藏时，窗口只留 6px 在屏内，窗口中心已经落到屏幕外；多屏时会被判到右邻屏，单屏时回退主屏。

**影响**：

- 隐藏后唤出、`_do_hide` 再次调用、边缘检测器、轮盘让位，可能使用另一块屏的 `availableGeometry`。
- 多屏下表现为「球在左屏，弹出跑到右屏」「轮盘圆心错位」「越唤越远」。
- 单屏下主要表现为回退主屏，和隐藏位/任务栏坐标不一致。

**修法**：吸附时保存 `QScreen`（或 name + geometry 快照），隐藏态一直用它；不要用屏外中心反推。

### P0-2 `_reveal_now(animated=True)` 停掉自己刚启动的动画

**代码**：`floatball.py::_reveal_now()` 先调 `_animate_move_to()`，随后 `self._slide_anim.stop()`。

**影响**：按住外滑从隐藏态开轮盘时，球可能没有真正弹出，但调用方已按「已移动」处理，200ms 后按旧位置开菜单。

**修法**：启动新动画前停旧动画；删除启动后的 `stop()`。

### P0-3 四个面板没有定位，直接 `show()`

**代码**：

- `floatball.py::_open_skills_panel()` → `panel.show()`
- `_open_clipboard_panel()` → `dlg.show()`
- `_open_command_panel()` → `dlg.show()`
- `_open_water_panel()` → `panel.show()`

`PanelShell` 是 `QDialog(parent)` + 固定尺寸；Qt 会把它居中到 parent（浮球），大面板直接盖住浮球；浮球贴边时还会被 Windows 推回屏内。

**修法**：`PanelShell.show_near(anchor)` 统一做：`screenAt`、`availableGeometry` 钳制、自动选侧、翻边、留边距、限制尺寸。

### P0-4 教程从隐藏位起播

**代码**：

- 默认配置 `snap_edge="right"`、`snap_hidden=True`、`onboarding_done=False`。
- `_restore_position()` 启动时就把球贴边隐藏。
- `start_onboarding()` 4.2s 后取 `_ball_rect_global()`，没有先 `_reveal_now()`。

**影响**：首启教程的聚光灯对准屏幕外的球；`screenAt(ball.center())` 可能回退主屏；气泡方向/箭头也跟着错。单屏就能复现。

**修法**：教程起播前先让球回到完全可见位；或使用「演示幽灵球」，不要移动真球。

## 4. P1：适配差的主要放大器

### 4.1 贴边与唤出

| 问题 | 代码 | 影响 | 修法 |
|---|---|---|---|
| 透明 edge detector 可能收不到鼠标 | `_setup_edge_detector()` | 全透明顶层窗在 Windows 分层窗口下可能鼠标穿透；光标已停在边上时新建窗口也不会补发 enter | 删检测窗，用 `QCursor.pos()` 轮询保存的边缘带 |
| 6px 可见标签太小 | `_do_hide()` `visible_tab=6` | 200% 下是 12 物理 px，但只占球 11%；圆角处更窄 | 已确认改为 **10–12px 可点击把手**；明确 hover 唤出与点击语义 |
| `availableGeometry` 隐藏进任务栏 | `_do_hide()` | 底部任务栏时球压住任务栏，可能挡点击 | 隐藏目标用 `geometry()` 或独立 tab；监听 `availableGeometryChanged` |
| 显示变化后不重新隐藏 | `_apply_display_change()` | 只把球放回可见位，不按 `snap_hidden` 重新缩回；`_hidden_now` 状态失真 | 变化后重新执行 hide/show，并重建 DPR 位图 |
| 负坐标被当成“未设置” | `_restore_position()` `x<0 or y<0` | 左侧/上方副屏的合法负坐标重启后丢失 | 用 `None` 哨兵，坐标交给 `screenAt` 校验 |
| 关吸附卡在 6px | 设置变更逻辑 | 只清 `_snapped`，不 reveal；`_show_full()` 因 `_snapped=False` 直接 return | 先 reveal，再清状态 |
| 菜单恢复位被清空 | `_open_radial_menu_now()` | `_ensure_ring_room()` 刚存的 `_snap_menu_restore` 被置 None，关菜单不回位 | 只在 None 时赋值 |
| 改尺寸不重贴边 | `widget_size_prop` | 以旧中心 recenter，吸附/隐藏态脱边 | resize 后按当前 edge 重算 |

### 4.2 自动弹出与面板

| 问题 | 代码 | 影响 | 修法 |
|---|---|---|---|
| 进程面板悬停不复查 | `_check_hover()` → `QTimer` → `_show_proc_panel()` | 鼠标快速划过，250ms 后仍弹 | 入口复查 `is_hovered` / 面板可见 / 拖拽状态 |
| 鼠标移入面板后浮球自动缩回 | `_auto_hide()` 只看 `is_hovered` | 球滑走，面板留在原地，锚点消失 | `_auto_hide` 检查面板可见/鼠标在面板内 |
| 进程面板无最大高度/滚动 | `ProcessPanel.show_for()` | Agent 多时向下溢出，`adjustSize` 后不重新钳位 | `QScrollArea` + 最大高度 + resize 后重定位 |
| 显示/收起动画竞态 | `show_for()` / `hide_panel()` | fade-out 与新 show 的透明度动画并行 | 统一显隐状态机，先 stop 旧动画 |
| 自动日报抢焦点 | `_open_news_panel()` + `QTimer.singleShot(500)` | 1000×640 自动弹，打断当前 Agent | 已确认：保留自动弹出，但必须 `WA_ShowWithoutActivating` + 限制尺寸（≤可用区 90%） |
| 加载提示用主屏 | `loading_indicator.py` | 浮球在副屏时提示跑到主屏 | 改 `screenAt(anchor.center())` |
| 固定尺寸 | `PanelShell.setFixedSize` | 1280×800 下 Skills 占 52%×65%；更小屏直接越界 | `min(设计, available-32)`，内容滚动 |
| 多实例/关闭中重开 | `_open_*_panel()` | 渐出期间 `isVisible()` 仍 true，可能 raise 已关闭面板；Clipboard/Command 可叠多个 | 加 `closing` 状态 + 单例复用 |

### 4.3 教程

| 问题 | 代码 | 影响 | 修法 |
|---|---|---|---|
| 全局/局部坐标混用 | `onboarding.py::bubble_geometry()` + `_apply_step()` | 副屏原点非 0 时，气泡被移动到屏幕外（实测副屏期望 x=2581，实际全局 x=4501） | `rect.translated(-overlay.geometry().topLeft())` |
| 气泡高度在定宽前测量 | `_apply_step()` 用 `sizeHint()` | 文本换行后高度变化，按钮行可能被裁 | 先定宽 → `layout().activate()` → `heightForWidth` → 再定位 |
| 演示移动球，覆盖层不跟随 | `onboarding.py` 只存构造时 `_ball` | 第 6 步贴边演示后，聚光灯留在旧位置 | `set_ball_rect()` 每步更新；或演示用 ghost |
| 菜单压住气泡 | 第 4/5 步打开真实轮盘/右键菜单 | 菜单 topmost 且晚于 overlay，遮住“下一步” | 演示步骤强制气泡在左/上，菜单反向偏移 |
| 定时器不取消 | `_snap_demo()` 的 700/2600ms `singleShot` | 用户 2.6s 内点下一步，教程结束后球仍被藏 | 保存 timer，cleanup 时 stop |
| 只覆盖一块屏 | overlay `setGeometry(screen_rect)` | 另一屏仍可操作；多屏穿帮 | 多屏遮罩或明确只允许当前屏交互 |
| 失焦后键盘失效 | `showEvent` 只激活一次 | 点另一屏/其他窗口后 Esc/Enter 无效 | 重新激活或全局快捷键 |
| 点击遮罩即前进 | `mousePressEvent` | 不判左右键/不判洞，双击连跳两步 | 只处理左键单击；洞内不前进 |
| 步骤数文案不一致 | `STEPS` 是 7 步，日志/Web 写 6 步 | 文案与进度不符 | 统一从 `len(STEPS)` 生成 |
| 首步 demo 丢失 | 构造内 `emit(0)`，外部 connect 在构造后 | 第 1 步悬停演示不执行 | 构造后 `QTimer.singleShot(0, ...)` |

## 6. 推荐修复架构

不要在每个面板里复制 `screenAt` / clamp。建议四层：

```text
ScreenContext
  QScreen + DPR + geometry + availableGeometry + screenKey
        │
        ├── AnchoredPopup.show_near(anchor, desiredSize, policy)
        │     → PanelShell / ProcessPanel / NewsWindow / WaterReminder
        │
        ├── SnapController
        │     free / snapped_visible / snapped_hidden / revealing / hiding
        │     存 edge + screen + tabRect；用 QCursor 轮询，不用透明检测窗
        │
        └── OnboardingLayout
              先 reveal 真球 → 取可见球 rect → 局部坐标气泡
              → 定宽后测高 → 菜单演示避让 → 可取消定时器
```

四条硬规则：

1. **屏幕只认 `QScreen`**：吸附/隐藏/唤出/轮盘共用同一 `QScreen` 快照，不用屏外中心反推。
2. **所有弹出面必须 `show_near`**：禁止裸 `show()`；自动弹出必须不抢焦点。
3. **尺寸必须可收缩**：设计尺寸是上限，不是固定值；内容用滚动，不靠窗口溢出。
4. **教程先让球可见**：演示不移动真球；必须移动时，覆盖层跟随。
