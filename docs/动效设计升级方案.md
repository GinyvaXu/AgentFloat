# AgentFloat 动效设计升级方案（v3.13 动效专项）

> 依据：`motion-ui-design` 守则（两套运动模型 / 微交互词汇库 / 反模式与验收清单）+ 对现有代码的全量盘点。
> 本文只讲**方案**：现状 → 目标 → 参数 → 验收。实施分批见 §8。
> 原则一句话：**布局按目标算，一切可见数值都是动画值；按下只反馈，松开才提交；弹是调料，不是主食。**

---

## 1. 现状盘点（事实）

### 1.1 已有基础设施

| 设施 | 位置 | 评价 |
|---|---|---|
| 弹簧引擎（单例 60fps 批处理、可打断、空闲停表） | `ui/motion.py` | **唯一有 dt 上限（MAX_DT=1/30）的动画源**，方向正确，应作为基座 |
| 面板渐入渐出 | `ui/anim.py`（200ms OutCubic / 150ms InCubic） | 固定时长曲线，可用但不参与"可打断/可重定向" |
| 面板外壳淡入淡出 | `ui/panel_kit.py` / `ui/panel_style.py` | 与 anim.py 功能重复，应合并 |
| 视觉令牌 | `ui/tokens.py`（RADIUS / FONT / SPACE） | 静态视觉已收敛；**动效令牌散落各处** |

### 1.2 逐帧绘制清单（无 dt、定时器一延迟就变慢）

| 位置 | 场景 | 现状 |
|---|---|---|
| `intro_animation.py` | 启动动画整屏 | 16ms×约 7s，纯函数 timeline（可测试），结束后仅 hide 未释放 |
| `floatball.py:645-650` | 单击涟漪 | 16ms 固定 +0.04/帧，约 400ms |
| `floatball.py:1956-1975` | 长按启动环 | 16ms 轮询，进度线性映射 |
| `floatball.py:2088-2094` | 移动模式跟随 | 16ms 直接 `move()`，无插值 → 高刷屏抖动 |
| `onboarding.py:129-158` | 聚光灯呼吸 | 33ms 固定 ±0.035/帧（30fps 且无 dt） |
| `loading_indicator.py:150-191` | 旋转环 / 进度条 | 16ms 固定步进，转速与真实进度无关 |
| `quote_window.py:303-322` | 自动关闭进度线 | 50ms 固定 +0.05/s，每 50ms 重绘整窗 |

### 1.3 曲线与时长

- 曲线只有四种：`OutCubic`（入场）/ `InCubic`（出场）/ `OutBack`（贴边弹入）/ `InOutCubic`（贴边滑出），弹簧 6 组（`motion.Tokens`）。
- **时长硬编码分散**：floatball 15 个值、intro 23 个值、面板 1500/1800ms、CSS/JS 各自一套；`quote_window` 自动关闭默认值 12s 与 8s 不一致。
- Web 端：只有 `ease`，无 `cubic-bezier`、无 `prefers-reduced-motion`、无 `requestAnimationFrame`。

### 1.4 已确认的问题（本文要治的）

1. 除 `motion.py` 外**所有逐帧动画都没有 dt 上限**（卡顿帧会一次性跳到终点或整体变慢）。
2. 涟漪/长按/移动跟随/呼吸/旋转/进度线 **各自 16~50ms 定时器**，与弹簧引擎并行跑，互不同步。
3. 浮球 `_animate_slide` 的 `QPropertyAnimation` **无 parent**，且覆盖引用前未 `stop()`（PyQt 下可能被 GC 中断）。
4. 环形菜单：确认脉冲 120ms 与 90ms 收合**错配**（脉冲没播完就收）。
5. `process_panel.hide_panel` 的 140ms 渐出回调与 `show_for` **存在竞态**（可能把刚显示的又隐藏）。
6. 大量 `windowOpacity` 动画（anim / quote / loading / water / process_panel）：Windows 透明窗上代价高、观感弱于内部绘制透明度。
7. `QGraphicsOpacityEffect` 用于 onboarding 气泡与喝水弹窗，且 onboarding **叠加了手写指数逼近**（两套机制）。
8. 无全局 reduced-motion：`set_reduced_motion` 只影响弹簧。
9. 启动动画不可跳过、结束后对象与全屏位图常驻。
10. Web：列表 `innerHTML` 全量重建 → 进度条 `width .3s` 过渡被反复重启；无合成层提示。

## 2. 目标形态（一句话版）

**所有会动的数都注册到一个动画源（motion），只有两种模型（指数平滑 / 弹簧），所有时长与距离都有令牌，所有逐帧定时器消失，静止时真的静止。**

---

## 3. 统一动效基础设施

### 3.1 `ui/motion.py` 扩为唯一动画源

保留现有弹簧（`Spring`/`MotionDriver`），补齐三件事：

| 新增 | 接口 | 用途 |
|---|---|---|
| 指数平滑值 | `Smooth(target, speed)` / `motion.smooth(key, target, speed=14)` | 位置跟随、滚动偏移、光标、移动模式跟随、进度线 |
| 统一 dt 与静息 | 引擎内 `dt = min(real_dt, 1/30)`；平滑值 `|Δ|<0.01px` 吸附，弹簧 `|Δ|<0.05px 且 |v|<0.5px/s` 停 | 卡顿帧不瞬移；停下不再计算（省电） |
| Kick（冲量） | `spring.kick(px)` | 甩出、落地抖动、输入框被撞、无路可退的推挤 |

**迁移规则**：所有现有 16/20/33/50ms 定时器改为向 motion 注册值，`paintEvent` 只读值不再自己推进。改造后 `rg "setInterval\(1[0-9]\)|setInterval\([235][0-9]\)"` 在 UI 目录应为 0 命中。

### 3.2 动效令牌（`ui/motion.py::Tokens` 扩充，CSS/JS 同源）

| 令牌 | 值 | 用途 |
|---|---|---|
| `DUR_IN / DUR_OUT` | 200 / 150ms | 面板与卡片显隐（沿用现有） |
| `DUR_TAP` | 90ms | 按压反馈（与收合对齐，修 §1.4-4） |
| `SMOOTH_FOLLOW` | speed 14/s | 元素位置跟随（浮球移动模式、光标高亮） |
| `SMOOTH_TEXT` | speed 16/s | 进度线、文字跑马灯 |
| `SPRING_UI` | ω 22, ζ 0.75 | 列表项、卡片选中条 |
| `SPRING_PAGE` | ω 16, ζ 0.85 | 页面/列切换 |
| `SPRING_TAP` | ω 45, ζ 1.0 | 按下压入（快、不回弹） |
| `SPRING_RELEASE` | ω 11, ζ 0.4 | 松开回弹（回弹只留给松开） |
| `SPRING_POP` | ω 26, ζ 0.45 | 勾选/收藏/角标弹入 |
| `DIST_TAP` | 2px（浮球等大元素 4px） | 按压位移 |
| `DIST_OVERPULL` | 6px（浮球 10px） | 边界过拉 |
| `DIST_PEEK` | 8px | 返回/收起 peek |
| `STAGGER_LIST / ROW` | 0.20 / 0.15 | 波浪（离选中越远越慢） |
| `CASCADE_LIST / ROW` | 10 / 6px | 离场级联滞后 |
| `SETTLE_HOLD` | 0.8s | 滚动条收缩等闲置判定 |

> 桌面端换算说明：守则数值来自 128px 宽的 OLED；桌面屏宽 1280~2560，若按比例会得到 20~100px 的位移，**不适用于密集桌面 UI**。本方案只对"大元素"（浮球、引导光斑）放大到 2 倍上限，其余沿用 1~8px 级。

### 3.3 统一 API 形态

```python
from agentfloat.ui import motion
# 跟随类（无过冲）
motion.follow("ball.follow_x", x, speed=motion.Tokens.SMOOTH_FOLLOW)
# 质量类（有惯性/可回弹）
motion.spring("menu.ring", progress, **motion.Tokens.SPRING_UI)
# 一次性冲量
motion.kick("quote.card", px=3)
# 每帧统一推进（由引擎内部驱动，业务只设目标）
```

**铁律落地**：业务代码只设 Target；不允许 `setValue` 式直写当前值（例外：父级携带、Snap/Jump、动画起点）。

## 4. 分模块方案

### 4.1 浮球本体（最高频交互）

| 交互 | 现状 | 目标 | 参数 |
|---|---|---|---|
| 悬停放大 | 弹簧（好） | 保留，改为 `SPRING_UI`，只重绘预渲染位图（已是） | ω22 ζ0.75 |
| 按下 | 弹簧 PRESS | `SPRING_TAP` 压入 + `DIST_TAP`(4px)；松开用 `SPRING_RELEASE` 回弹 | 45/1.0 → 11/0.4 |
| 单击涟漪 | 16ms 固定步进 | 改指数平滑驱动的 `ripple_p`（`SMOOTH_TEXT`），Kick 起振；静息即停 | speed 16/s |
| 长按启动环 | 16ms 线性 | 平滑进度 + **前段加速后段减速**（用 ζ=1 弹簧跟随目标，天然先快后慢）；到 100% 触发 | ω 12, ζ 1.0 |
| 贴边滑入/滑出 | QPropertyAnimation 120/150ms | 统一走弹簧 `SLIDE`；**修 stop/GC**（加 parent、覆盖前 stop）；位移改为过拉 + 回弹（`DIST_OVERPULL` 10px） | ω 20, ζ 0.8 |
| 贴边让位/弹出 | 170ms OutBack | 弹簧 `SPRING_PAGE`，避免 OutBack 对窗口位置的越界溢出 | ω 16, ζ 0.85 |
| 轮盘延迟打开 | 200ms singleShot | 改为**等让位动画静息**再开（事件驱动，不再拍数字） | — |
| 退出收拢 | 弹簧 + windowOpacity 线性联动 | 保留弹簧，透明度改为内部绘制（见 §4.4） | QUIT 300/28 |
| 移动模式跟随 | 16ms 直接 move | `motion.follow`（speed 14）+ dt 上限；落点 Snap | speed 14/s |
| 引导贴边演示 | 700/2600ms 固定时序 | 改为动画静息回调链（演示 → 静息 → 滑回） | — |

### 4.2 环形菜单

- **展开/收拢**：沿用弹簧 `RING_OPEN/RING_CLOSE`（420/28、460/34）。
- **扇区错峰**：保留 `progress - i*0.04` 相位差（符合"波浪"），但错峰因子改从 `Tokens.STAGGER_ROW` 读。
- **按压反馈**：`DUR_TAP` 90ms 与收合启动对齐（修错配）；按下 `DIST_TAP` 2px + 轻微倾斜（anticipation），松开才执行动作。
- **光标高亮**：20ms 轮询 → `motion.follow`（speed 18）+ 只在值变化时 `update()`；按住时零延迟转发（保留）。
- **边界**：菜单转到头/尾时给 `DIST_OVERPULL` 6px 过拉回弹，不 Kick、不越界。

### 4.3 语录浮窗

| 项 | 现状 | 目标 |
|---|---|---|
| 入场 | opacity 220ms + pos 260ms OutCubic（每次换条重播） | 换条只做**内容交叉淡入**（120ms），窗口位移只做首次 |
| 出场 | 180ms 无缓动 | `DUR_OUT` 150ms + `InCubic`，与入场对称 |
| 自动关闭进度线 | 50ms 固定步进、每 50ms 重绘整窗 | `motion.follow`（speed 16），只在进度变化时重绘进度条区域（`update(rect)`） |
| 悬停 | 暂停 | 保留，暂停时进度线也停（同一动画源，避免不同步） |
| 复制反馈 | 1200ms 文案复位 | 用统一 `flash()`（淡出 150ms 后隐藏），不再硬切 |
| 默认时长不一致 | 12s vs 8s | 统一取设置值，兜底 8s（单一来源） |

### 4.4 面板族（panel_kit）

- **显隐**：`panel_kit` 的 fade 与 `anim.py` 合并为一个实现；时长取 `DUR_IN/DUR_OUT`，Esc 与 ✕ 同路径。
- **透明度实现**：不用 `windowOpacity`，改为 `paintEvent` 内绘制整体 alpha（`QPainter.setOpacity`）+ 子控件随父级绘制 → 避免 Windows 透明窗的软件合成开销（与 §1.4-6 一致）。
- **列表增删（快报/剪贴板/命令）**：
  - 新增项：在落点从 0 高度展开（`SPRING_UI`），其后项同步让位（共享参数与目标，禁止互相追逐）；
  - 删除项：朝中线收拢到 0（ζ=1，防"翻出来"），**静息后才 `deleteLater`**；
  - 删的是选中项：选中态平滑移到接替项；删空则隐藏选中。
- **搜索过滤**：过滤后的列表用 `STAGGER_LIST/ROW` 波浪重排（不做整块平移）；清空关键词时反向。
- **空态切换**：空态与列表之间用 120ms 交叉淡入（同一动画源），不闪跳。
- **状态文案**：`flash()` 统一 150ms 淡出（skills/command/clipboard 的 1500/1800ms 硬切统一）。
- **列/分栏切换（快报窗）**：左栏切换用 `SPRING_PAGE`；右栏内容换条用 120ms 交叉淡入。

### 4.5 引导（onboarding）

- 聚光灯呼吸：33ms 固定 → `motion.follow`（正弦目标由平滑值追），dt 上限；**且只在可见时推进**。
- 气泡：去掉 `QGraphicsOpacityEffect` + 手写指数逼近的双机制，改 `paintEvent` 内 alpha（同一动画源）；位移用 `SPRING_PAGE`。
- 演示动画（贴边滑回）：改为静息回调链（同 §4.1）。
- 全流程支持 reduced-motion：呼吸与位移关闭，仅保留静态高亮。

### 4.6 启动动画（叙事保留，机制升级）

- 保留 timeline 纯函数（可 seek、可测试）；把 16ms 自推进改为向 motion 注册的**每帧统一推进**，dt 上限 1/30。
- 增加**可跳过**：任意点击/按键 → 立即到落位帧（`Snap` 到终点 + 涟漪一次）。
- 结束后 `deleteLater()` 释放全屏位图与光晕缓存（修 §1.4-9）。
- 支持 reduced-motion：跳过飞行与星点，直接淡入落位。
- 预算：整屏绘制 ≤ 4ms/帧（现有优化后 2.77ms，改造不得回退）；启动到可用 ≤ 2.5s。

### 4.7 加载指示器 / Toast

- 旋转环角度与进度条宽度：16ms 固定 → `motion.follow`（speed 16），转速与真实进度挂钩（进度未知时用"呼吸式"不确定态）。
- Toast：入/出场统一到弹簧 `PRESS`/`RING_CLOSE`（已是），停留时长改令牌（`SETTLE_HOLD`×2），移动模式 600000ms 的超长停留改为"随移动结束收起"。

### 4.8 喝水提醒弹窗

- 去掉 `windowOpacity` + `QGraphicsOpacityEffect` 双机制，改内部绘制 alpha；入场 220ms `OutCubic` 保留但走令牌。
- 卡片落位加 `DIST_TAP` 级挤压-回弹（按下"确定"时），确认动作在松开时提交。

### 4.9 Web 端

| 项 | 现状 | 目标 |
|---|---|---|
| 令牌 | 只有 `ease` 与零散秒数 | 与 `ui/motion.py::Tokens` 同源的 `--dur-*` / `--ease-*`（本轮已同步圆角/间距令牌，动效令牌下一批） |
| 曲线 | 全部 `ease` | 入场 `cubic-bezier(0.22,1,0.36,1)`（≈OutCubic），出场 `cubic-bezier(0.4,0,1,1)`（≈InCubic），弹入 `cubic-bezier(0.34,1.56,0.64,1)` |
| 列表重建 | `innerHTML` 全量重建，过渡被重启 | 增量更新（只改变化的行）+ `will-change: transform` 仅在动画期间加 |
| 进度条 | `width .3s` 反复重启 | 改 `transform: scaleX()` + `transform-origin: left`，并节流到 ≤ 20 次/秒 |
| 无障碍 | 无 | `@media (prefers-reduced-motion: reduce)` 关闭位移/呼吸，仅保留 ≤ 80ms 的透明度变化 |
| 滚动 | `scrollIntoView({behavior:"smooth"})` | 保留（原生曲线合理），加 `scroll-behavior: smooth` 兜底 |

## 5. 反模式整改对照（守则 §5）

| 反模式 | 本项目现状 | 整改 |
|---|---|---|
| 直接写当前值 | 涟漪/长按/移动/呼吸/旋转自推进 | 全部改设 Target（§3.1） |
| 布局按 Current 算 | 列表让位处未见明显问题 | 增删动画期间布局按 Target 计算，补测试 |
| 两元素互相追逐 | 语录进度线与其 `_auto` 计时器不同步 | 单一动画源 + 同一目标 |
| 线性 + 固定时长 | 多（见 §1.3） | 令牌化 + 曲线统一 |
| 过度弹跳 | 弹簧 ζ 多在 0.26~0.34（偏弹） | 只在大元素/落位用 <0.5；密集列表用 0.75~1.0 |
| 一切都在动 | 浮球 16ms 悬停轮询常开、radial 20ms 常开 | 改为事件驱动 + 值变化才重绘 |
| 删除立即销毁 | 列表重建用 deleteLater（好），intro 未释放 | 静息后释放（§4.4/§4.6） |
| 转场互相依赖 | 轮盘延迟与让位时长硬编码 | 改静息事件驱动 |
| 距离感丢失 | 贴边/让位用 12~20px 级 | 收到 1~8px（大元素 ≤ 10px） |
| 掩盖抖动 | 未见 | 保持：先保帧率，不加 blur |

## 6. 验收清单（逐条可测）

1. **单一动画源**：`rg "setInterval\((1[0-9]|2[0-9]|3[0-9]|50)\)" src/agentfloat/ui` → 仅 motion 内部命中。
2. **按下只反馈**：录制浮球/菜单/弹窗交互，确认无"按下即执行"路径（菜单项、删除、关闭、确定均松开提交）。
3. **边界反馈**：菜单到端、列表到顶/底、面板拖到屏幕边 → 有 6px（大元素 10px）过拉回弹，无越界。
4. **列表增删**：新增从 0 高度展开、删除收拢静息后才释放（打点日志验证 `deleteLater` 时机）。
5. **波浪与级联**：离选中越远越慢/滞后（帧序列截图对比）。
6. **静止段**：交互结束后 1s 内 CPU 应回落到空闲基线（现有基线：51.9MB / ≤3.7% 单核）。
7. **帧率无关**：debug 构建下注入 30fps 与 120fps 两种刷新，动画轨迹一致（timeline 可 seek 校验）。
8. **断帧保护**：人为阻塞主线程 300ms，动画不瞬移（dt 上限生效）。
9. **无泄漏**：`QPropertyAnimation`/`QGraphicsOpacityEffect` 全部有 parent 或持有引用；动画结束对象释放（引用计数快照对比）。
10. **连续操作**：连点浮球 10 次、快速开关菜单、动画中反向 → 无抖动、无累积误差。
11. **reduced-motion**：系统开启"减少动画"后，位移/呼吸/飞行关闭，功能不受影响。
12. **预算**：启动动画 ≤ 4ms/帧、面板打开 ≤ 16ms 首帧、Web 端无长任务 > 50ms。

## 7. 风险与取舍

| 风险 | 说明 | 应对 |
|---|---|---|
| 弹簧参数迁移导致"手感变了" | 用户已适应现有浮球手感 | 分批：先基础设施与低风险项（进度线/涟漪/加载），浮球与菜单参数**保持现值**再微调 |
| 内部绘制透明度改造面大 | 涉及 anim/quote/loading/water/process_panel 五处 | 抽 `paintEvent` 通用混入，逐处替换 + 抓图回归 |
| Web 增量更新改动大 | 快报列表/进程列表都在用 `innerHTML` | 先做令牌与 reduced-motion，增量更新放最后一批 |
| 启动动画可跳过改变"仪式感" | 产品叙事 | 默认保留完整播放，仅点击/按键跳过；reduced-motion 下直接落位 |
